# تجهيز موقع رواق لـ Google Search Console

تم التأكد من وجود وسم التحقق داخل `src/routes/__root.tsx` ضمن إعدادات `head.meta`:

`<meta name="google-site-verification" content="QryOSp4Ct4QwGaQG-0ebeq_vYbsKkql6_WHvgGfdlRQ" />`

## خطوات إكمال الربط

1. انشر المشروع على استضافة تدعم تطبيقات TanStack Start وتشغيل الخادم، مع إعداد متغيرات البيئة وقاعدة البيانات إن كانت مطلوبة. المشروع ليس صفحة HTML ثابتة، وقد يحتاج إعدادات نشر خاصة.
2. افتح الرابط العام المنشور في نافذة خاصة بدون تسجيل الدخول إلى Grok، وتأكد من ظهور الموقع دون إعادة توجيه إلى صفحة تسجيل دخول.
3. افتح مصدر الصفحة (View Page Source) وتأكد من ظهور `google-site-verification` في قسم `<head>` من الصفحة المنشورة.
4. في Google Search Console أضف خاصية من نوع URL prefix باستخدام الرابط المنشور نفسه، ثم اختر HTML tag وليس HTML file، واضغط Verify.
5. إذا لم يظهر الوسم في مصدر الصفحة، تحقق من إعدادات النشر وإخراج الخادم قبل إعادة المحاولة.

**مهم:** وجود الوسم في ملفات المشروع لا يثبت أن الموقع منشور أو أن Google يستطيع الوصول إليه. لم يتم نشر الموقع أو التحقق من ملكيته آلياً ضمن هذه الحزمة.
